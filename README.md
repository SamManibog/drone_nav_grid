# Drone Nav Grid

A rust-native python extension module for drone navigation data structure

## Prerequisites

In order to use this library, you must have the following dependencies installed:

 - Rust (Click [here](https://rust-lang.org/tools/install/) to install Rust)
 - Python & Pip (Click [here](https://www.python.org/downloads/) to install Python)

## Installation

Once prerequisites have been installed, you may then install this extension module to your computer.

First, clone the repository.
`git clone https://github.com/SamManibog/drone_nav_grid --depth 1`

Second, run the built in python installation script.
`cd drone_nav_grid
python install.py`

## Usage

Once installed on your local machine, you may then import the data structure in your Python project with
`from drone_nav_grid import NavGrid`
